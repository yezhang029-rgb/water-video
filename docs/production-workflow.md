# 避免局部优化偏离目的的制作方法

适用于下一部视频。本次不重做已结束样片，不强制所有作品采用同一引擎或画风。

## 先决定观众要经历什么

每片先用一页说明：给谁看、讲清一个什么问题、观众从什么感受走到什么感受、哪个镜头值得记住。信息不足时给少量有区别的创意方案并解释取舍，不直接展开几十个镜头。

## 分镜必须能验证

| 项目 | 应回答的问题 |
| --- | --- |
| 段落作用 | 为什么必须有它？去掉后损失什么？ |
| 开始与结束 | 主体从什么状态变成什么状态？ |
| 动作和镜头 | 主体怎么动，摄影机怎么动，观众看哪里？ |
| 前后因果 | 为什么接这一镜，如何把视线交给下一镜？ |
| 声音与节奏 | 音乐何时进入、蓄势、落点或收束，字幕读多久？ |
| 审查重点 | 给定时间能否看懂？动作、数字和事实是否可信？ |

“银河很震撼”“镜头拉远”“递一杯水”不足以指导完整制作，需落实到上述状态和节奏。

## 尽早看整片骨架

先做低成本全片带声动态分镜：可以用简单形状、占位素材，但要有大致真实的镜头时长、字幕停留、转场和音乐结构。先检查全片逻辑与情绪，再针对最难动作或画风做5–10秒验证，最后展开精修。

不必等每段精修后才第一次看整片。特效、字体、配色变好，不等于故事和节奏成立。

## 每次修改回到目的

记录本次问题对观众的影响，说明方案服务于哪个段落作用；执行后查看改动处、相邻镜头与全片节奏。常规修正直接推进；改变主题、叙事顺序、关键隐喻或大幅改变时长时，解释影响并与用户讨论。

局部改进若破坏已确认的整体意图，给出代价与备选。当前镜头表、简报和决定同步更新，旧分镜与新成片不能长期并列而不标状态。

## 收尾与交接

先检查创作目标，再检查播放、编码、音轨、音量、时长和交付。主动指出最影响体验的1–3个问题，处理可修复项。人类审美反馈、动作可信度与技术检查分别报告；没实际主观试听不能声称听过。

新会话先读当前目标、阶段、用户决定和未解决问题，避免从旧日志拾起已完成的任务。
