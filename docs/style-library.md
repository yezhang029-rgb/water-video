## 它是什么

库内为15种动态设计风格提供示例成片、完整提示词及源码，示例大多为10秒。按说明，主体画面采用SVG、Canvas、WebGL、Three.js等，3D示例还用Blender；有的使用照片素材。通用渲染接口是window.renderAt(t)，通过逐帧捕获再合成视频，并非可直接导入Remotion的15个主题。

用户说已下载过，实际位置未核实。使用时先选示例和提示词，按新片知识表达改写题材、解说、时长和结构；保留适合的视觉技法，不能照搬10秒广告式节奏。必要时只适配相关代码到选定引擎。

## 有序使用方式

1. 先在线看相关风格；未选用前只记录链接，不把整个示例仓库塞进water-video。
2. 新片确定一个知识问题，写明观众原本怎样理解、看完能解释什么、关键证据在哪里。
3. 选1–2种能解释问题的风格，读取对应prompts、demos和节奏线索，不只复制风格名称。
4. 在独立实验项目做短验证；沿用哪种引擎、是否需要Blender和音频工具，按样例实际依赖决定。
5. 回到全片带声动态分镜，知识逻辑、停留时间和音乐节奏成立后再精修。不能因风格示例漂亮而把全片目的换成展示技法。

README提示：重现源码需要Node、Chrome、FFmpeg及Python等工具，字体需另行准备，3D路线另需Blender。代码、提示词等有项目许可证，第三方素材与字体另有条款，实际复用时按选用部分保留许可和来源。
